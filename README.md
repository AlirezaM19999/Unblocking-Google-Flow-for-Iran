## 🚀 About the Project

**Unblocking Google Flow for Iran** is a community-oriented project focused on improving accessibility to [Google Flow](https://labs.google/fx/tools/flow), Google's AI-powered video creation tool.

The repository contains a browser-extension project intended to help users dealing with Google Flow access restrictions.

> **Important:** This project is not a VPN or proxy service. It does not independently change your IP address, bypass network filtering, or guarantee access to Google Flow. Actual access may still depend on Google's regional policies, account eligibility, and server-side restrictions.

## ✨ Project Goals

- 🌊 Improve the accessibility experience for Google Flow users.
- 🧩 Provide a browser-based approach.
- 🛠️ Make installation and usage easier to understand.
- 🌍 Support the Persian-speaking developer and AI community.
- 🤝 Encourage community feedback and open-source collaboration.

*These are project goals, not a guarantee that every restriction can be bypassed.*

## 📦 Installation

### Step 1 — Download the Repository

Download the project as a ZIP archive:

<p align="center">
  <a href="https://github.com/AlirezaM19999/Unblocking-Google-Flow-for-Iran/archive/refs/heads/main.zip">
    <img src="https://img.shields.io/badge/Download-Source%20Code-blue?style=for-the-badge&logo=github" alt="Download Source Code" />
  </a>
</p>

Extract the downloaded archive to a folder on your computer.

### Step 2 — Open Your Browser's Extensions Page

For Google Chrome, open:

```text
chrome://extensions/
```

Enable **Developer mode**.

### Step 3 — Load the Extension

1. Click **Load unpacked**.
2. Select the extracted extension directory.
3. If the browser accepts the directory, the extension should appear in your extensions list.

**Note:** Select the directory containing the extension's `manifest.json` file. If the downloaded source does not contain a valid extension manifest, it cannot be loaded this way.

### Step 4 — Open Google Flow

Visit the official website:

[https://labs.google/fx/tools/flow](https://labs.google/fx/tools/flow)

Test the extension and follow any instructions provided by the project.

## 🧰 Troubleshooting

| Problem | What to check |
|---|---|
| Extension fails to load | Confirm that the selected folder contains a valid `manifest.json`. |
| Google Flow still shows a region error | Check Google's current availability and your account's eligibility. |
| Google Flow does not open | Check your connection, browser console, and any relevant error messages. |
| Extension appears but has no effect | Verify that the extension is enabled and compatible with your browser. |

No workaround is guaranteed to work for every account or network.

## 🔐 Security & Privacy

Before installing any browser extension:

- Review its source code before granting permissions.
- Check the permissions requested in `manifest.json`.
- Never share your Google password, session cookies, or authentication tokens.
- Be cautious when installing modified or repackaged versions.
- Disable or remove the extension if it behaves unexpectedly.

## 🇮🇷 فارسی

### درباره پروژه

این پروژه با هدف کمک به بهبود دسترسی کاربران ایرانی به **Google Flow**، ابزار هوش مصنوعی گوگل برای ساخت ویدیو، توسعه داده شده است.

### نصب افزونه

۱. سورس پروژه را از GitHub دانلود و از حالت فشرده خارج کنید.

۲. در مرورگر Chrome آدرس زیر را باز کنید:

```text
chrome://extensions/
```

۳. گزینه **Developer mode** را فعال کنید.

۴. روی **Load unpacked** کلیک کنید و پوشه‌ای را انتخاب کنید که فایل `manifest.json` افزونه داخل آن قرار دارد.

۵. سپس سایت [Google Flow](https://labs.google/fx/tools/flow) را باز کنید و عملکرد افزونه را بررسی کنید.

### نکات مهم

- این ابزار VPN نیست و IP شما را تغییر نمی‌دهد.
- دسترسی به Google Flow تضمین‌شده نیست.
- قبل از نصب، کد منبع و مجوزهای افزونه را بررسی کنید.
- این پروژه مستقل است و ارتباط رسمی با گوگل ندارد.

### حمایت از پروژه

اگر پروژه برای شما مفید بود، می‌توانید آن را در GitHub ستاره‌دار کنید، مشکلات را گزارش دهید یا در توسعه آن مشارکت کنید.
